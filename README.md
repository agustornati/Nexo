## Stack

- **Backend:** Python 3.12 + FastAPI
- **Frontend:** React 18 + TypeScript + Vite + TailwindCSS
- **Base de datos:** PostgreSQL 16
- **Storage:** MinIO
- **Infra:** Docker Compose
